My take on [Ralph](https://www.aihero.dev/getting-started-with-ralph)

## To Use
1. Tell the agent what you want to build
2. `/prd` to create:
    - `./tracks/PRD.md`
    - `./tracks/TRACK.md`
    - `./tracks/progress.txt`
3. Run `ralph.sh`
